# MemoryDungeon

**MemoryDungeon** expands upon the traditional memory game by incorporating elements of roleplay, roguelike gameplay, and a PvE experience.

- [Version 1](./Godot/):
    - Tech stack: [Godot](https://godotengine.org/)

- [Version 2](./Qt/):
    - Tech stack: [Qt](https://www.qt.io/) in C++

- [Version 3](./C/):
    - Tech stack: C/C++ Windows Forms

The current codebase in this repository provides a reference for the [rule](./rule.pdf) of the game.

Demo is available [here](http://memorydungeon.junbinzhang.com/)
